## The courses

The repo explains the patterns. The courses add worked solutions in six languages, runnable tests, and a browser environment to write them in.

| Course | For |
|---|---|
| [Grokking the Coding Interview](https://www.designgurus.io/course/grokking-the-coding-interview) | The 41 patterns and more than 300 problems. This repo is its free companion. |
| [Grokking Data Structures](https://www.designgurus.io/course/grokking-data-structures-for-coding-interviews) | If arrays, lists, trees, and heaps are still the weak spot |
| [Grokking Algorithm Complexity and Big O](https://www.designgurus.io/course/grokking-algorithm-complexity-and-big-o) | If reasoning about complexity is the weak spot |
| [Grokking the Art of Recursion](https://www.designgurus.io/course/grokking-recursion-for-coding-interview) | If recursion and backtracking are the weak spot |
| [Grokking Dynamic Programming](https://www.designgurus.io/course/grokking-dynamic-programming) | The DP patterns in far more depth than this repo goes |
| [Grokking Graph Algorithms](https://www.designgurus.io/course/grokking-graph-algorithms-for-coding-interviews) | Graphs beyond breadth first and depth first search |
| [Grokking Multithreading and Concurrency](https://www.designgurus.io/course/grokking-multithreading-and-concurrency-for-coding-interviews) | Concurrency questions in depth |
| [Grokking 75](https://www.designgurus.io/course/grokking-75-top-coding-interview-questions) | A short list when the interview is close |
