## The order that works

1. [Recognize the pattern](recognize-the-pattern.md), so you have a routine for the first minute.
2. [What complexity passes](what-complexity-passes.md), so the constraints stop being decoration.
3. Work through [the patterns](../patterns/) and [the problems](../problems/).
4. [Flashcards](flashcards.md) as you go, to find the gaps.
5. [Interview communication](interview-communication.md) and the
   [edge cases checklist](edge-cases-checklist.md) in the last week.
6. [All 41 patterns](all-41-patterns.md) the night before, and nothing else.
